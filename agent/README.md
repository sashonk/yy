# Автоматическое прохождение уровней (dev-агент)

Папка содержит инструкции и скрипты для запуска игры и автоматического
прохождения уровней через встроенный dev-агент (`DevAgentServer`, порт 8765).

## Содержимое

| Файл              | Назначение                                                        |
|-------------------|-------------------------------------------------------------------|
| `README.md`       | эта инструкция                                                    |
| `solve.ps1`       | скрипт прохождения: replay сохранённых решений + BFS-решатель     |
| `walkthrough.json`| сохранённые решения уровней (ходы)                                |
| `last_run.log`    | лог последнего запуска `solve.ps1`                                |

## 1. Сборка и запуск игры

```powershell
# сборка (однократно)
mvn install -Pdesktop -DskipTests

# запуск с dev-агентом (HTTP-сервер на 127.0.0.1:8765)
java "-Djava.library.path=D:\work\yy\desktop\target\natives" `
  -jar D:\work\yy\desktop\target\yy-desktop-1.0-SNAPSHOT-jar-with-dependencies.jar agent
```

Аргумент `agent` поднимает `DevAgentServer`. Дополнительно есть `dev`
(режим разработки) и `clear` (сброс прогресса).

## 2. HTTP API dev-агента

| Запрос                       | Описание                                          |
|------------------------------|---------------------------------------------------|
| `GET  /state`                | состояние: экран, уровень, ходы, `won`, `busy`, `rotten`, поле `cells` (x, y, item, spot), список UI-акторов |
| `POST /move?dir=up|down|left|right` | ход игрока                                |
| `POST /click?name=<actor>`   | клик по именованному актору (например `winNext`)  |
| `POST /start?level=N`        | перейти на уровень N                              |

Оси: `up` = y+1, `down` = y-1, `left` = x-1, `right` = x+1.
`busy=true` — идёт анимация хода (ждать перед следующим ходом).
`won=true` — появилось окно победы.

## 3. Скрипт solve.ps1

```powershell
# пройти уровни 1..5 (сначала пробует сохранённые решения, иначе BFS)
powershell -NoProfile -ExecutionPolicy Bypass -File agent\solve.ps1 -From 1 -To 5

# пройти произвольный список уровней
powershell -NoProfile -ExecutionPolicy Bypass -File agent\solve.ps1 -Levels "1,4,13,21,29"

# принудительно пересчитать решения BFS и обновить walkthrough.json
powershell -NoProfile -ExecutionPolicy Bypass -File agent\solve.ps1 -From 1 -To 5 -ForceSolve

# только replay из walkthrough.json, файл не обновлять
powershell -NoProfile -ExecutionPolicy Bypass -File agent\solve.ps1 -From 3 -To 7 -NoSave
```

Параметры: `-BaseUrl` (по умолчанию `http://127.0.0.1:8765`), `-From`, `-To`,
`-Levels` (список уровней через запятую, приоритетнее `-From/-To`),
`-ForceSolve`, `-NoSave`, `-MaxStates` (лимит BFS, по умолчанию 200000),
`-MoveDelayMs` (пауза между ходами, по умолчанию 150 мс).

Результат пишется в консоль и в `agent\last_run.log`.

**Важно:** `solve.ps1` должен содержать только ASCII-символы — Windows
PowerShell 5.1 читает `.ps1` без BOM как ANSI, и кириллица в строках ломает
парсер. Сообщения в скрипте — на английском, лог пишется в UTF-8.

## 4. walkthrough.json

```json
{ "levels": { "1": { "moves": ["right","down"], "steps": 2, "updated": "2026-09-19" } } }
```

Скрипт сверяет сохранённые ходы с актуальным полем (симуляция); при
несовпадении (уровень изменён) — пересчитывает BFS и обновляет файл.

## 5. Правила игры, заложенные в решатель

- Все белые фигуры (Yang) двигаются **одновременно** на 1 клетку за ход.
  Порядок обработки — от «ведущих» по направлению хода.
- Стены (Wall), металл (Metal) — препятствия.
- Земля (Ground) — остаётся под фигурой и вновь проявляется, когда она ушла.
- Ящики (Box) и вода (Water) — толкаются, только если следующая за ящиком
  клетка пуста. При этом вода, на которую фигура заходит «в лоб»
  (клетка ящика), поглощается — толкание и поглощение различаются
  направлением входа (Water — наследник Box в коде игры).
- Fall — падающий блок: после каждого хода падает вниз до упора
  (гравитация, `Game2.java:834-868`).
- Зеркала (Mirror) — двигаются в сторону, **противоположную** ходу.
- `rotten` — на покинутых клетках вырастают стены.
- Победа — каждая фигура Yang/Mirror стоит на клетке со «spot» (Yin).

### Ограничения

- В `GET /state` не видно Ground, стоящего ПОД Yang в начальной позиции
  (движение это учитывает, но стартовое состояние неразличимо).
- BFS в PowerShell медленный: для больших/сложных уровней поднимайте
  `-MaxStates` или сохраняйте найденные решения.

## 6. Инструкция для ИИ-ассистента (повторное прохождение)

При просьбе «пройти уровни N..M»:

1. Собрать и запустить игру с аргументом `agent` (см. п.1), запуск в фоне.
2. Выполнить `powershell -NoProfile -ExecutionPolicy Bypass -File agent\solve.ps1 -From N -To M`.
3. Прочитать `agent\last_run.log` и проверить, что все уровни `DONE`.
4. Новые решения автоматически сохраняются в `agent\walkthrough.json`
   и переиспользуются при следующем прохождении.

# Yin Yang (yy)

Головоломка на тему инь и ян, личный проект на [libGDX](https://libgdx.com/).
Репозиторий: https://github.com/sashonk/yy

## Правила игры

Задача — совместить всех белых половинок Ян с неподвижными чёрными половинками Инь.
Двигаются только белые фигуры, причём **все одновременно** и по горизонтали, и по
вертикали — одно движение пальцем сдвигает всю «стаю». На поле встречаются
препятствия (камни, стены, вода, металл, зеркала), которые можно обратить себе
на пользу.

- ~150 уровней в двух «сторонах» — светлой и тёмной
- Внутриигровая валюта «яни», подсказки (прохождение), платный набор уровней
- Локализация: русский, английский, немецкий
- Прогресс хранится в зашифрованных preferences (TEA)

## Стек

- Java 8, Maven (мультимодульный проект)
- libGDX 1.7.0 / gdx-box2d 1.7.2, box2dlights 1.4
- Рантайм [Spriter](https://github.com/Trixt0r/spriter) (SCML-анимации) и
  BodyEditorLoader — вендорены в `core`
- Платформы: desktop (LWJGL), Android, HTML (GWT 2.6), iOS — исторически;
  сейчас реально собирается и запускается только desktop

## Сборка и запуск (desktop)

Нужны JDK 8+ и Maven.

```bash
git clone https://github.com/sashonk/yy.git
cd yy

# собрать самодостаточный jar
mvn package -Pdesktop

# запустить
java -jar desktop/target/yy-desktop-1.0-SNAPSHOT-jar-with-dependencies.jar

# либо запуск прямо через Maven (без сборки jar)
mvn integration-test -Pdesktop
```

Окно 1024×768, главный класс `com.me.yin_yang.Main`.

Аргументы запуска:

| Аргумент | Действие                                                            |
|----------|---------------------------------------------------------------------|
| `dev`    | режим разработки (в т.ч. встроенный редактор уровней `EditorGame2`) |
| `agent`  | поднять dev-агент — HTTP-сервер на порту 8765 для управления игрой  |
| `clear`  | сбросить сохранённый прогресс                                        |

Покупки и реклама на desktop — заглушки (`Main.java` реализует
`IActivityRequestHandler` без биллинга).

## Структура

| Модуль    | Назначение                                              |
|-----------|---------------------------------------------------------|
| `core`    | Игровая логика, экраны, ресурсы — собирается всегда     |
| `desktop` | LWJGL-лаунчер, dev-агент — включается профилем `-Pdesktop` |
| `android` | Android-бэкенд (старый android-maven-plugin)            |
| `html`    | GWT-бэкенд                                              |
| `ios`     | iOS-бэкенд (RoboVM)                                     |
| `assets`  | Ресурсы: уровни, атласы, шрифты, звуки, l10n            |

Модули платформ подключаются Maven-профилями (`-Pdesktop`, `-Pandroid`,
`-Phtml`, `-Pios`), по умолчанию собирается только `core`.

Ключевые пакеты в `core`:

- `com.me.test` — каркас: `TestGame`, экраны, настройки, звук, l10n,
  `SecuredPreferences` (шифрование сохранений)
- `com.me.test.game2` — сама игра: экраны меню и уровней, контроллер,
  сценарий победы, редактор уровней
- `com.me.test.game2.item.factory` — фабрики элементов поля (камень, вода,
  металл, зеркало, стены, ян)
- `com.brashmonkey.spriter`, `aurelienribon.bodyeditor` — вендоренные библиотеки
